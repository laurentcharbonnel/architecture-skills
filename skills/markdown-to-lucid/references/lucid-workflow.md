# Lucid workflow

## Discover capabilities

Use the connected official Lucid MCP server; prefixes vary by client. Load `lucid://skills/readme` first. Read the current diagram specification before **each** Standard Import creation, and the sequence specification before sequence creation. For scripts, inspect the catalog and load API documentation; load layout guidance before layout work. Do not guess classes or methods.

If disconnected, finish local Markdown/model and explain the missing connection. Skill installation does not authenticate. Never embed credentials.

## Create selected views

Select exactly the listed elements/relations. Canvas IDs must be document-wide unique, e.g. `c2__task_manager`, while semantic IDs remain stable. Save returned document/page/item IDs, generator IDs and edit URLs in a small mapping JSON. Resume from that mapping rather than creating duplicate documents.

At C2/C3 put only focus children inside the boundary; contextual internal elements stay blue outside it. Discover supported editable person silhouettes/store symbols. Do not call a rectangular actor placeholder full visual conformity. Defaults: internal `#DBEAFE`, external `#E5E7EB`, text `#0F172A`, people `#155A91`; this encodes the agreed convention, not a corporate palette. Size text before placing shapes.

Honor server routing for supplied Mermaid/SVG. Flat images do not satisfy editable C4 output. Native UML source-backed sequences are suitable when editing limitations are disclosed. Preserve participant order, types, aliases, arrow semantics, branches and notes.

## Verify

Read the actual document. Fetch metadata first for unknown sizes, then required pages/regions. Process bulky readbacks locally and return compact differences.

**Semantic:** compare element sets, names, types, descriptions, known technology/deployment, boundaries, ownership, directed edges and labels. Exclude mapped decorations from architecture counts. Normalize whitespace only.

**Sequences:** load available UML API documentation and read the actual generator source. Generic fetch was observed to omit actor/database messages and normalize arrows. Exact native-source equality proves source retention, not rendering. Confirm nonempty output and inspect exports. If source differs, compare participants/messages/order/arrow types/branch tree. Missing coverage is unverified, not passed.

**Visual:** export each page; inspect readable text, silhouettes/cylinders, colors, boundaries, routing and overlap. Validators alone are insufficient. Reroute automatically first; inspect current items/locks before edits. Adjust labels without changing meaning, validate and export again. At most three repair passes on the same document; report remaining defects. Recheck semantics after substantive repairs.

Save one report row per view: expected/actual counts, semantic differences, visual differences, unavailable checks and link. For sequences include participant/message counts and native-source coverage. Do not promise pixel identity.

## Edits and failures

A timed-out creation may have succeeded: inspect/search before retrying. Preserve collaborator edits. Review manual changes against the saved model, then update Markdown only when requested. Ungrouped sequences may no longer match generator source; inspect the editing mode. Report deltas rather than repeating full documents.
